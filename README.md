# modnyk
Modnyk is an online clothing store built with the Django framework.

Features
User can:
- browse a list of products;
- view detailed information about each product;
- leave reviews and read reviews from other users;
- register and verify their accounts via email confirmation;
- upload a profile photo and edit personal information;
- automatically save their address as default for future orders;
- add products to the shopping cart and see the total amount;
- place and manage orders
